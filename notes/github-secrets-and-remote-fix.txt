==============================================

The original site stays at https://skivn-ha.github.io/PASC/
Do not change that repository, and do not change the poker-pasc API key.

This folder is the new project. Its GitHub Pages site is separate.
The new web key is restricted to:

  https://skivn-ha.github.io/*
