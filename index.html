Poker Manager Help

What this app is

Poker Manager is a club tournament helper for social poker nights. It runs in your browser (and can be installed as an app on phones). It handles player registration, table seating, blind timing, cash tracking, points, and optional phone remote control.

The shared season lives on the club server: players, points, settings, and pools. A club email opens that shared season. A username opens only the copy on this device.

Signing in

  • From the splash screen, press Login. Enter an email or a username, then the password.
  • An address with @ signs in to the club server. If this device is not already on the latest server file, the app asks whether to Load latest or Keep this device.
  • A username without @ is a local committee login. It does not read or change the shared season.
  • If this browser is already signed in with an email, Continue as that address opens the app again.
  • The top right shows Server or Local, then the player name or username and a user icon. Click the name or icon to Log out.
  • An email signs in to the shared season. It must match the email on a player in Player Management, and the top right then shows that player's name. Committee players get every tab. Other players get Points Table, Blind Timer, and Numbers.
  • Create those emails in Firebase. The app has no sign-up form. An email that is not on the player list can still sign in as committee, so an admin can publish the season.

Typical game night flow

  • Settings: Confirm club name, season, blinds, payout %, and optional features (ghost player, bonus hand, raffle, teams event, game vouchers, remote, numbers).
  • Registration: Enter game details, add players, and assign tables.
  • Tables: Open Tables and press START GAME. Seats are shown around each table.
  • Blind Timer: Run the clock, announce blinds, and (if Remote is enabled) show the join code/QR for phones.
  • Eliminate players from the Tables tab or from a joined phone Remote until one winner remains.
  • Game Dashboard: Review cash, pools, and results, then Save Game to the Points Table.
  • Optionally email or print the game stats. With a club email, Save Game also updates the shared season.

Main tabs

The tab for the page you are on is highlighted orange. Log out is the user icon at the top right, not a tab.

  • Registration: Game details, player check-in, assign tables, raffle cash (if enabled).
  • Tables: Shown once tables are assigned. Start Game is at the top. Players sit around the table images. Hidden again if the game is cleared.
  • Game Dashboard: Live cash breakdown, prize pools, ghost/bonus/bad beat tracking, points for the current game, save/email/print.
  • Blind Timer: Levels, countdown, fullscreen timer, voice announcements, cash prize display.
  • Numbers: Random number picker for draws or side games. Hidden until enabled in Settings → General.
  • Points Table: Season standings from saved games, and qualification for the season final.
  • Remote: Host or join live remote control (if enabled in General settings).
  • Settings: All club configuration (committee access required).

Registration & tables

  • Players can be typed in or chosen from the Player Management list.
  • Tables fill using the Maximum Players per Table setting.
  • Teams Event (if enabled in Settings → General) appears in Game Details and lets players compete in pairs. When disabled, the option is hidden.
  • After Assign Tables, open Tables and press START GAME. Use Eliminate on a seat. When one player remains, use Winner.
  • The app can auto-combine remaining players toward a final table as seats free up.

Blind Timer & voice

  • Configure levels, break times, and announcement voice in Settings → Blind Timer.
  • Voice choice is saved per device. Phones may only expose a few real system voices.
  • On Android, install more voices in the phone’s Text-to-speech settings if options sound the same.

Game Dashboard & cash

  • Buy-in cash splits using Club Cash % and Player Cash Payout % from settings.
  • Top 3 places use the payout percentages (3rd is calculated automatically).
  • Raffle Cash (if enabled) is entered on Registration and Game Dashboard and feeds club cash / optional bonus pools.
  • Ghost Player, Bonus Hand, and Bad Beat Bonus each have enable/disable settings and season pools.
  • Save Game locks the night into Points Table / Game Management history. Declaring a winner does not do this by itself.
  • When signed in with a club email and committee access, that save uploads the whole shared season about a second later. A username login keeps the night on this device only.

Points Table & season

  • Points are awarded from finishing places in each saved game.
  • Minimum Games Played to Qualify for Season Final marks who has played enough games (0 = off).
  • Birthday bonuses can highlight players in their birthday month when enabled.
  • Season Statistics summarises season cash and optional club expenses.
  • Clear Season Data removes game history for a new season without wiping players/settings.

Remote Control

  • Enable in Settings → General. Disable hides the Remote tab.
  • When enabled, starting a game can auto-host; the Blind Timer can show the game code and QR for a set number of minutes.
  • Phone joins with the code/QR, then can eliminate/restore players and control the blind timer.
  • While joined, the phone can keep the screen awake and play synced voice announcements.
  • After a winner is declared, remotes automatically leave about 1 minute later. Hosting stops when the game finishes.

Settings overview

Optional features are switched on and off with small slider switches — green means enabled, grey means disabled. Switch changes save immediately; other fields use the Save Settings button.

  • General: Club name, club logo, season, max players/table, season-final qualification, and switches for Raffle Cash, Teams Event, Game Vouchers (with voucher value), Remote Control (with QR display minutes), the Random Number Generator, and emailing stats when a game is saved.
  • Blind Timer: Voice, blind levels, set all times, breaks, and whether the next blind level is shown.
  • Club Cash & Payout: Club vs player cash split and 1st/2nd place payout %. 3rd place is calculated from the remainder.
  • Bonuses: Ghost Player, Bonus Hand, Bad Beat, and Birthday — optional season features and pool amounts.
  • Player Management: Player records (name, email, phone, date of birth, years, membership, committee). These names fill the registration list.
  • Security / Login: Master Password for the admin username, plus a local username and password for each committee member. Other members sign in with the email on their player record. Create that email in Firebase Authentication.
  • Game Management: List and delete saved games. The eye opens a game, and the date in the top-left box can be changed. Deleting a game also removes it from the Points Table.
  • Season Statistics: Season totals and club expenses.
  • Backup / Restore: Publish from this device, load the latest server file, or export, email, and import a file backup.
  • Reset App: Clear season data, or factory-reset players, settings, and history. An email sign-in also updates the shared season.
  • Remote Sync: Dev-only Firebase override for live remote hosting.
  • About: App name, version, license details, and this Help guide.

Shared season

  • The server file is the latest players, settings, pools, and saved games. Other committee members receive it when they sign in with a club email.
  • Save Game uploads it automatically for a committee email login. With Email stats when a game is saved turned on, that same login also emails the stats from the club Gmail to every player email address. A username login does not send that email.
  • Publish from this device sends this device’s season to the server. Use it on the laptop that has the real latest season when the server is still empty, or when this device should replace the server copy.
  • Load latest from server replaces this device with the server file.
  • On email login, if this device does not already match the server, choose Load latest or Keep this device. Keeping this device does not overwrite the server.
  • File Export still downloads a backup. It includes the app version, club name, and local export time. Import replaces this device’s copy and, for a committee email login, can then upload.

Club Cash & Payout Settings

Configure how buy-in cash is split between club funds and player payouts, and the top-three prize percentages.

Bonuses

Optional season bonus features. Enable each one with the switch, then set amounts and manage pools.

Ghost Player

Amount taken from each game before the percentage split. Builds up each game until the ghost player wins, then resets.

Current pool: $0.00

Bonus Hand

Season bonus hand (e.g. Straight Flush 6–10). Each game, the set amount is taken from raffle cash and added to the pool until won.

Current pool: $0.00

Bad Beat Bonus

When a player holding quads loses to a higher hand, they win the bad beat bonus. Each game, the set amount is taken from raffle cash and added to the pool until won.

Current pool: $0.00

Birthday Bonus

Track players with birthdays this month and mark when their birthday bonus has been paid. Paid status resets each year when their birthday month comes around again. When disabled, birthday icons and bonus tracking are hidden throughout the app.

Blind Timer Settings

Configure blind levels, break times, and the voice used for timer announcements.

Game Management

Saved games in the order they were played. Deleting a game also removes it from the Points Table.

Season Statistics

Season totals from saved games. Enter club expenses for the season on the right.

Reset App

Use these carefully. Season reset clears saved game history only. Factory reset clears everything and restores defaults.
